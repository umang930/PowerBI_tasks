# Task 1 – Financial Health Dashboard

## Overview

This project was developed as part of my **Power BI Internship**.

The objective of this task is to build an interactive Financial Health Dashboard using Power BI to analyze financial performance, profitability, financial statements, cash flow, and future trends.

## Objectives

- Analyze overall sales and profitability.
- Track financial performance across different products, countries, and business segments.
- Analyze Income Statement data.
- Analyze Balance Sheet data.
- Analyze Operating, Investing, and Financing Cash Flows.
- Identify profitability trends over time.
- Forecast future sales and profit for financial planning.
- Present financial insights through interactive Power BI dashboards.
