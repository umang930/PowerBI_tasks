# Task 2 – Human Resources Analytics Dashboard

## Overview

This project was developed as part of my **Power BI Internship**.

The objective of this task is to build an interactive Human Resources Analytics Dashboard using Power BI to analyze employee attrition, workforce demographics, employee satisfaction, performance, recruitment metrics, and hiring trends.

## Objectives

- Analyze employee attrition and turnover.
- Track workforce distribution and employee demographics.
- Analyze employee satisfaction and performance.
- Analyze recruitment sources and hiring metrics.
- Identify factors associated with employee attrition.
- Forecast future hiring requirements.
- Provide interactive HR insights through Power BI dashboards.

## Tools & Technologies

- Microsoft Power BI
- Microsoft Excel / CSV
- DAX
- Data Visualization
- HR Analytics
- Forecasting

## Dashboard Pages

1. HR Workforce Overview & Attrition Analysis

- Total Employees

2. Predictive Hiring & Workforce Planning

3. Employee Insights & Workforce Analysis

- Workforce Distribution by Job Role
- Average Employee Engagement

- Average Time to Hire
